# 三方比对与整改闭环业务规则

规则版本：three-way-v8-20261026。以下口径适用于分析、对话和受控工具建议。

- 最终目标是综资、现场、资产三方一致。三方比对发现问题；整改闭环台账负责管理员审核、分责处理和验收。AI 只解释确定性规则、原始数据与已保存的人工判断，不代替管理员改数据、判型号、建单或验收。
- 比对仅限所选同一导入批次、现场已确认完成的机房，先按所选综资机房的地点编码过滤资产表；综资基线已更新时以最新基线的地点编码为准。资产以最新上传的资产信息表为准；综资以本轮任务清单及其最新基线为准；现场以小程序有效反馈及有留痕的修正为准。综资基线可在盘点完成后更新，不重建现场任务，保留历史版本。
- 三组均以网元/资源名称为业务关联键，条码只用于关联后的核对。第一组按同一任务内综资网元名称与现场所属网元名称完全匹配；设备记录编号只用于核验归属，不能覆盖名称冲突。现场网元名称、地点编码来自所属综资清单，并非现场独立采集。第二、三组都先限定为同一机房地点编码，再按资产信息表“资源名称”与综资“网元名称”完全匹配，首尾空格可忽略。即使名称或条码相同，也不得把其他地点编码的资产带入本机房；多个机房同时比对时，也要分别关联各自机房内的资产。找不到时报告“资产表未找到对应资源名称”，不可凭相同条码猜测或替代资源名称。综资或资产出现同名多条时，标记“同名多条，待管理员关联”，不可自动选一条。设备、ODF/IODF 机架、未关联资源、数量统计、导出和 AI 分析均遵守同一地点编码范围；范围内找不到对应名称时报告缺失，不跨机房兜底关联。
- 设备比对和 ODF/IODF 机架核对分开。传输综合柜随设备盘点，属于设备侧；不得因为 SPN/OTN 规格型号含“机架”“机柜”就改判为 ODF/IODF。机架按资产表明确的资源类别、资产名称、资源名称中的 ODF/IODF 标识及已登记机架识别；资产表独有机架也应在机架核对展示为现场未反馈。历史机架仅作参考，不能充当本次现场反馈；机架不比型号，缺少综资机架基线时不能声称机架三方一致。
- 资产条码唯一不等于资源名称唯一；同一资源可对应多条码，所有条码都需保留。资源名称为空的条码单独列为未关联资源，不计作具名设备或机架。资产条码总数应等于设备类、机架类、未关联资源三类条码数之和；设备比对条目数、资源名称数、资产条码数必须区分，不能把三者当成同一数量。未提供机架或未关联资源明细的 AI 上下文只能说明已传入的设备范围。
- 第一组“综资与现场”：核对设备资产条码和设备机架号；设备型号由管理员单独判断。设备机架号不能用机柜资产条码代替；机柜资产条码留待单独比较。
- 第二组“综资与资产”：综资网元名称对应资产资源名称；核对设备资产条码、地点编码；综资设备型号与资产规格型号由管理员单独判断。
- 第三组“现场与资产”：按所属网元核对设备资产条码、地点编码。现场地点编码取综资任务清单，资产地点编码取资产信息表。不能将这项比对误说成两套独立采集地点的对比。
- 条码、机架号、地点编码只忽略首尾空格，保留内部字符及前导零；必需值缺失或重复不能判一致。报告差异时列出两方原值与来源。现场实际扫到的条码必须原样保留，不得用综资期望条码或资产表条码回填。登记无条码、缺码或同一设备多资产条码需管理员处理；多条码沿用完整人工核对模式 B，不把多个条码自动拆成多个设备。
- 两处型号各有“待判断 / 一致 / 不一致 / 无法确认”人工结论。AI 和规则不能从字符串相同、相近或不同自动推断型号结论。源型号变化后旧判断保留历史，当前重新待判断；缺任一必需型号不能判断为一致。
- 自动差异只是候选问题。管理员确认后按同一网元建单；现场问题可派给现场人员，综资和资产问题由管理员在原系统处理并更新基线或资产快照。已完成任务锁定，现场反馈错误可由管理员依据凭证修正并留痕，无需整间机房重盘。
- 验收以最新三组比对和两处有效型号判断为准，缺失、重复、待关联、待判断、无法确认或差异未消除都不能闭环。保留建单时原值、版本、处理人、判断依据与验收历史。盘点完成或处理说明本身不能证明三方一致。
- 只根据后端明确传入的范围、版本、原值、规则结论和人工判断回答。缺少资产快照、地点编码、现场反馈或人工型号结论时，应具体说明缺项，不猜测哪个系统应改，不声称已完成三方核对或闭环。部分机房和截断上下文不能当作全网结果。
