# 盘亏盘盈拼销使用说明

拼销用于确认“一条盘亏记录和一条盘盈记录实际上是同一台设备”。设备类别取任务清单的“设备类别”，在资产盘点数据表和下载文件中展示。

## 操作入口

1. 在“资产盘点数据”查询并勾选机房。
2. 找到盘亏或盘盈设备，点击操作栏的“拼销”。普通设备仍显示“修改综资”。
3. 按机房名称、设备类别、关键字筛选；可勾选“仅本机房”。盘亏找盘盈，盘盈找盘亏，支持跨导入批次。
4. 选择候选，核实网管身份、序列号、照片等实物证据，填写确认依据，点击“确认同一设备并拼销”。

候选只来自各机房最近一次有效的已完成盘点。未完成、作废、已有拼销的记录不参与；涉及未闭环整改单时，须先处理现有工单。

打开弹窗时，只推荐设备条码相同（含部分条码相同）或网元／资源名称相同的最多 15 条记录，条码匹配优先。没有推荐时显示空列表，不自动列出全部盘亏盘盈。

管理员输入机房、设备类别、关键字，或勾选“仅本机房”后再查询。查询结果每页显示 15 条，可翻页查看；修改筛选条件后点击“查询”，从第一页重新查找。仅型号相同、仅机柜条码相同不会自动推荐。

## 确认后的数据

| 情况 | 展示和处理 |
|---|---|
| 同机房 | 合为一条有效设备；综资参考取盘亏记录，现场型号、设备条码、机柜位及机柜条码取盘盈记录 |
| 跨机房 | 合并设备归实际找到的机房；原机房保留“已拼销迁出”，不重复计入有效设备数 |
| 调拨 | 标记“待跨机房调拨”，仍须在综资及资产原系统完成相关调整 |
| 三方比对 | 使用合并结果继续核对；资产仍按所选机房地点编码取数，型号继续由管理员判断 |
| 下载 | 资产盘点数据保留拼销状态、来源及去向；“导出设备比对”增加“拼销记录”工作表 |

设备条码相同优先显示，但必须人工确认；仅型号相同、仅机柜条码相同不能证明是同一台设备。多资产条码设备须核实整组归属。

## 撤销与重新核实

已拼销行点击“拼销记录”，填写撤销原因后撤销，双方恢复未拼销的展示，可重新选择。原始采集记录一直保留，小程序已完成任务仍只读。

已有拼销的设备，页面不再提供单独修正和转整改入口，需先撤销。若来源资料、有效盘点任务或相关综资记录变化，原拼销提示“待重新核实”，不继续合并；修改后改回旧值也须重新核实。确认、撤销均记录操作人、时间和依据。
