# 现场测试操作指引

适用场景：把当前项目从本机开发调试，切到现场体验版/现场测试环境。

这份文档只写最常用的操作，不改代码，按步骤执行即可。

## 1. 先确认你要切的是什么

这个项目的“切换”主要分三层：

1. 小程序登录模式：`dev` / `trial`
2. 后端运行方式：本机直启 / Tunnel 对外访问
3. 微信体验版：重新上传后才会生效

所以不是只点一个按钮就结束，通常要一起做。

## 2. 切到 trial

在项目根目录运行：

```powershell
.\switch_miniprogram_mode.bat
```

然后选择：

```text
2
```

含义是：

- 小程序从开发测试账号切到真实微信登录
- 后端切到真实微信登录流程
- 现场人员用体验版时走公网 API

切完后，建议重启后端和重新上传小程序。

## 3. 启动后端

推荐用这个脚本：

```powershell
.\start_backend_tunnel.ps1
```

启动时会做这些事：

- 读取本地 `.env`
- 设置后端环境变量
- 提示你输入 `WECHAT_SECRET`
- 启动 FastAPI 后端

启动后，确认这两个地址能打开：

```text
http://127.0.0.1:8000/health
https://api.equip-inventory.xyz/health
```

正常时都应返回：

```json
{"status":"ok"}
```

## 4. 确认 Tunnel 常驻

你这套环境里，Tunnel 是靠 `cloudflared` 服务常驻的，不是只靠窗口临时跑。

检查命令：

```powershell
Get-Service Cloudflared
```

期望结果：

```text
Status: Running
StartType: Automatic
```

再补一条进程检查：

```powershell
Get-Process cloudflared
```

如果服务在跑，但公网地址不通，再测：

```powershell
Invoke-WebRequest https://api.equip-inventory.xyz/health
```

只要这里正常，说明 Tunnel 已经把公网 API 接到本机后端了。

## 5. 上传微信体验版

切到 `trial` 后，要重新上传小程序体验版。

现场测试时重点看这几点：

- 体验版里使用真实微信登录
- `miniprogram/env.js` 里的 `prodApiBase` 指向公网 API
- 微信开发者工具里不要停留在开发模式的旧包

当前项目里，体验版走的是：

```text
https://api.equip-inventory.xyz/api
```

## 6. PC 后台怎么开

PC 后台只适合在运行后端的这台电脑本机打开：

```powershell
.\start_admin_vue.bat
```

地址是：

```text
http://127.0.0.1:5173
```

注意：

- 不要把 PC 后台当成对外系统
- 别的电脑直接访问 `127.0.0.1:5173` 没意义

## 7. 现场测试前的最小检查

建议按这个顺序过一遍：

```text
1. switch_miniprogram_mode.bat 选择 2
2. start_backend_tunnel.ps1 启动后端并输入 AppSecret
3. Get-Service Cloudflared 确认 Running
4. 访问 https://api.equip-inventory.xyz/health
5. 重新上传微信体验版
6. 用现场微信账号登录测试
```

## 8. 常见问题

### 8.1 登录失败

优先检查：

- `WECHAT_APPID` 是否配置
- `WECHAT_SECRET` 是否输入
- 微信体验版是否重新上传
- 体验成员是否已加入

### 8.2 小程序提示网络错误

优先检查：

- `https://api.equip-inventory.xyz/health` 是否通
- `cloudflared` 服务是否在跑
- 本机后端是否还在监听 `127.0.0.1:8000`

### 8.3 PC 后台打不开

优先检查：

- `start_admin_vue.bat` 是否启动
- `127.0.0.1:5173` 是否被占用
- 后端 `8000` 是否正常

### 8.4 AI 分析不可用

这通常不影响盘点主流程。

优先检查：

- 本地 `9000` agent 是否启动
- `DEEPSEEK_API_KEY` 是否配置
- `INVENTORY_AI_AGENT_URL` 是否可达

## 9. 一句记忆版

```text
切 trial -> 启后端 -> 看 Tunnel -> 重新上传体验版 -> 现场账号登录
```
