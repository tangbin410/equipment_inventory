# 机房建模规则与使用说明

更新日期：2026-11-13

## 入口与操作

后台左侧“盘点数据”下方增加“机房建模”，完整管理员和协作管理员均可查看。

1. 按机房名称、领取人或全部已完成机房查询，在弹窗中单选机房。每个机房只列最近一次已完成盘点；盘点中的任务不进入候选，后端也会拒绝读取未完成任务作为建模资料。
2. 勾选传输综合柜、ODF、IODF 中需要展示的类型，至少选择一项，点击“生成模型”。修改机房或数据类型后，旧模型清除，需重新生成。
3. 拖动旋转、滚轮缩放，Shift＋拖动平移。使用总览、俯视、正面、背面和排号筛选查看布局。点击“全屏查看”放大模型区域，全屏中可继续切换视角、筛选排号及查看对象资料；点击“退出全屏”或按 Esc 返回。
4. 点击模型对象或在下方按编号、设备名称、型号、设备条码、机柜／机架条码模糊查找，点击“定位”查看资料。
5. 查看模型异常；更正应回到“盘点数据”处理，再重新生成模型。未定位记录不再单独展示明细列表；编号无法定位的资料仍不放入场景。本页不修改盘点反馈，也不保存新布局。
6. 生成模型后，点击“导出 HTML”，下载当前机房及所选类型的独立模型文件。双击文件即可离线旋转、缩放、筛选排号、搜索条码、全屏查看和点柜查看设备；无需登录或启动后台。

导出文件保留导出时的模型数据，默认以全机房总览打开，并显示盘点完成时间与导出时间。后台资料变化后，需重新生成并导出。导出内容不包含账号、登录令牌或后台接口地址。

首版仅使用系统已有资料，不支持任意 Excel 上传建模。查询任务概览后，只加载选定机房的明细，不一次性加载所有机房的设备。

## 对象与数据口径

| 对象 | 数据来源 | 模型表达 |
| --- | --- | --- |
| 传输综合柜 | 所选任务设备盘点的当前有效结果汇总，含管理员修正、有效拼销投影 | 蓝色设备柜，展示设备归属 |
| ODF | 所选任务独立登记的有效 ODF 机架明细 | 青绿色光纤配线架，面板为示意 |
| IODF | 所选任务独立登记的有效 IODF 机架明细 | 紫色成端配线架，面板为示意 |

设备只关联传输综合柜，不装入 ODF／IODF。盘亏、未扫、作废记录及拼销迁出记录不作为现场实物放入模型。多台设备提到同一柜位时合并柜体；**一台设备关联多个机柜属于正常业务关系**，每个关联机柜都展示该设备，设备总数按记录 ID 去重，不因此提示异常。柜位编号数量不等于已核实的物理柜数量。

当一条设备反馈同时包含多个机柜位和多个机柜条码时，不假设条码与位置按书写顺序一一对应，也不把所有条码复制到每个柜位。能够从单柜反馈确定对应关系的条码显示在柜位资料中；其余条码保留在该设备的关联机柜条码信息中，不因此阻止机柜建模。

## 已确认的建模规则

- 统一单位为 **毫米（mm）**，替代前期样板中确认过的厘米口径。
- 半深柜／机架外形：600×300×2200 mm；无末字母、占满双面槽位的整柜：600×600×2200 mm。
- 传输综合柜的安装容量按 **47U**；**1U＝44.45 mm**，47U＝2089.15 mm。U 安装高度与柜体外形高度分开，不把 47U 当成外部高度。
- 编号首字母固定 A，第二个字母表示排，接着两位数字表示排内位置，末字母 A／B 表示背靠背两面。例如 AB09A 是第 2 排第 9 位 A 面。
- AC01A 与 AC01B 背靠背；AC01 没有末字母，独占该位置两面。ODF／IODF 使用相同编号定位规则。
- 每排 01 都从左侧起，向右递增，下一排不反转，按 Z 字形展示。保留缺号与缺排，不压缩填补。
- 所有机房统一：俯视时每格上半部是 A 面，下半部是 B 面。从 AA 排开始，最外侧为 A 面，背靠背另一侧为 B 面；AB 及后续各排顺序完全相同，不逐排反转。模型正面视角朝向 A 面，背面视角朝向 B 面；不据此推断机房门的位置。

## 数据校验与精度

大小写、全角字符和常见分隔符可规范化；实际编号缺位、不符合 AA01A／AA01 格式或位置为 00 时，不猜号、不自动修改原记录，列入未定位资料。

同位置多个条码、同条码多个位置、整柜与半深柜重叠、不同类型同面占位等情况提示待核实。待核实对象不落实体，相同槽位显示一次待核实地面框，仍可从列表查看各条记录。

当前没有采集设备起始 U 位、占用 U 数、真实排间距、机房边界和端口成端关系。柜内设备的安装顺序与高度、ODF／IODF 面板、排间距、地面边界均为示意；不据此计算 U 位利用率、真实可用空间、真实机房面积或光纤连接关系。缺号也不代表该位置为空。

后续若要精确设备上架，需补充起始 U 位、占用 U 数及编号方向，校验 1–47U 边界与同面重叠；本版不自动推断这些值。
